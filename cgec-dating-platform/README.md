# CGEC Dating Platform

A modern full-stack dating & social feed platform for Cooch Behar Government Engineering College (CGEC) students.

## Features
- **Student Accounts (Boys & Girls)**: Profile creation with department, year, bio, and direct local photo file uploads.
- **Instagram-Style Feed**: Photo posts with double-tap heart animations, like counters, comments, and adaptive aspect ratio photo containers.
- **Swipe & Match Discovery**: Interactive Tinder-style swipe cards (Like, Super Like, Pass) with celebration match popup.
- **Direct Messaging & Chat**: Real-time chat inbox, message history, photo attachments, and online badges.
- **Modern UI**: Dark glassmorphism theme, gradient accents, responsive for mobile and desktop.

## How to Run

1. **Install Python Dependencies**:
   ```bash
   pip install -r requirements.txt
   ```

2. **Launch Server**:
   ```bash
   python server.py
   ```

3. **Open Website**:
   Open `http://localhost:8000` in your web browser.
